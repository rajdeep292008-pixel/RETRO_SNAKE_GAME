# Snake Neon-Retro - CRT Arcade Engine Prototype

An immersive, terminal-themed responsive retro arcade application prototype replicating the iconic 1970s block-grid game mechanics. This file uses HTML5 Canvas and real-time linear rendering loops to build an authentic cyberpunk aesthetic.

## 🌟 Key Integrated Modules
- **CRT Monitor Shader Mimicry:** Advanced layered CSS pseudo-elements overlaying a micro-scanline gradient matrix and variable RGB color-bleed tracking to simulate vintage green-phosphor hardware tubes.
- **Asynchronous Web Audio API synthesizer:** Built-in programmatic audio node framework running a client-side square-wave oscillator instance that triggers live acoustic telemetry signals (440Hz feed cues / 100Hz crash drops) without static audio files.
- **Dynamic Framerate-Independent Stepper:** Interactive system gameloop handled by native `requestAnimationFrame` hooks using delta timestamp throttling to increment the difficulty scale dynamically by decreasing step delay cycles as points accrue.
- **Persistent High Score Matrix:** Active connection layer to standard browser `localStorage` variables that pulls, updates, and structures historical player score states inside string-padded UI trackers.

## 🛠️ Built With
- **HTML5 Canvas API:** Low-overhead direct pixel manipulation grid layout using dynamic `pixelated` rendering properties.
- **Vanilla ECMAScript Engine:** Lightweight tracking algorithms monitoring relative linear 2D vectors ($dx$, $dy$) to evaluate boundary crashes and coordinate overlaps.
- **Google Fonts Web System:** Implements the monospace `VT323` digital font tracking matrix for absolute vintage terminal replication.
